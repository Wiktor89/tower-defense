# Tower Defense — Защита от зомби

Простая браузерная tower defense в стиле Plants vs Zombies.

## Запуск

Нужен локальный HTTP-сервер (модули ES6):

```bash
python3 -m http.server 8080
```

Откройте [http://localhost:8080](http://localhost:8080) в браузере.

## Как играть

1. **Собирайте солнце** — кликайте по падающим ☀️ или ставьте подсолнухи.
2. **Выберите растение** в панели сверху и **кликните на клетку** газона.
3. **Защитите дом** слева от 5 волн зомби.

## Растения

| Растение | Стоимость | Описание |
|----------|-----------|----------|
| 🌻 Подсолнух | 50☀️ | Периодически даёт солнце |
| 🌱 Горохострел | 100☀️ | Стреляет горохом по зомби в ряду |
| 🥜 Орех | 50☀️ | Прочная преграда |
| 🍒 Вишневая бомба | 150☀️ | Взрывается и уничтожает зомби рядом |

## Зомби

- 🧟 Обычный зомби
- 🧟‍♂️ Зомби с конусом (больше HP)
- 🪣 Зомби с ведром (ещё больше HP)

Проигрыш — если зомби дойдут до дома 5 раз. Победа — отбейте все 5 волн.

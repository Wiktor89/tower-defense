# Браузерные мини-игры

Коллекция простых игр на HTML5 Canvas и JavaScript.

## Запуск

Нужен локальный HTTP-сервер (модули ES6):

```bash
python3 -m http.server 8089
```

Откройте [http://localhost:8089](http://localhost:8089) — появится меню с играми.

## Как добавить новую игру

1. Создайте папку `games/<название>/` с `index.html` и ресурсами.
2. Добавьте запись в `js/games.js`:

```js
{
  id: 'my-game',
  title: 'Моя игра',
  description: 'Краткое описание',
  icon: '🎯',
  url: 'games/my-game/',
  available: true,
  tags: ['аркада'],
}
```

3. Перезагрузите страницу — игра появится в меню.

## Tower Defense — Защита от зомби

### Как играть

1. **Собирайте солнце** — кликайте по падающим ☀️ или ставьте подсолнухи.
2. **Выберите растение** в панели сверху и **кликните на клетку** газона.
3. **Защитите дом** слева от 5 волн зомби.

### Растения

| Растение | Стоимость | Описание |
|----------|-----------|----------|
| 🌻 Подсолнух | 50☀️ | Периодически даёт солнце |
| 🌱 Горохострел | 100☀️ | Стреляет горохом по зомби в ряду |
| 🥜 Орех | 50☀️ | Прочная преграда |
| 🍒 Вишневая бомба | 150☀️ | Взрывается и уничтожает зомби рядом |

### Зомби

- 🧟 Обычный зомби
- 🧟‍♂️ Зомби с конусом (больше HP)
- 🪣 Зомби с ведром (ещё больше HP)

Проигрыш — если зомби дойдут до дома 5 раз. Победа — отбейте все 5 волн.

## Столбик — 30 000 примеров

Тренажёр сложения и вычитания столбиком — «30 000 примеров» Узоровой О.В. и Нефёдовой Е.А.

- Выбор класса (1–3): однозначные, двузначные или трёхзначные числа
- Режимы: только сложение, только вычитание или случайно
- Ввод ответа по цифрам в столбик, как в тетради
- Счёт правильных и неправильных ответов
